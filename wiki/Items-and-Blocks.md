# Items and Blocks

A catalogue of what the mod adds. Items also appear in three creative-mode tabs: **Machine Tab**, **Component Tab** and **Minerals Tab**. Recipes can be looked up in JEI or Create's recipe viewer.

## Machines and rocket parts

| Name | What it is | See |
|---|---|---|
| Rocket Engineer Table | Designs engines | [Rocket Engines](Rocket-Engines.md) |
| Rocket Controls | Required control block of every rocket | [Building a Rocket](Building-a-Rocket.md) |
| Rocket Engine | Designed engine (comes with a nozzle structure block) | [Rocket Engines](Rocket-Engines.md) |
| Small Rocket Engine, Big Rocket Engine | Fixed-stat legacy engines, no recipe | [Rocket Engines](Rocket-Engines.md#legacy-fixed-engines) |
| Rocket Casing | Decorative casing | [Machines](Machines.md#rocket-casing) |
| Clamps | Immovable block | [Machines](Machines.md#clamps) |
| Flight Recorder | Launch diagnostics | [Machines](Machines.md#flight-recorder) |
| Air Liquefier | Liquid oxygen / CO₂ from air | [Machines](Machines.md#air-liquefier) |
| Mechanical Electrolyzer | Water → hydrogen + oxygen | [Machines](Machines.md#mechanical-electrolyzer) |
| Catalyst Carrier | Methane and monopropellant synthesis | [Machines](Machines.md#catalyst-carrier) |
| Oxygen Sealer | Pressurises rooms | [Oxygen Sealer](Oxygen-Sealer.md) |
| Cryogenic Tank | Portable 4 000 mB cold-fluid tank | [Machines](Machines.md#cryogenic-tank) |
| Flow Meter | Pipe flow gauge | [Machines](Machines.md#flow-meter) |
| Copper / Netherite Oxygen Backtank | Chest-slot oxygen tank; also placeable | [Spacesuit and Oxygen Backtank](Spacesuit-and-Oxygen-Backtank.md) |

Engine structure blocks (Engine Structure, Small Engine Structure, Big Engine Structure) are the nozzle halves that appear automatically when you place an engine. You do not craft them.

## Engine components

| Name | Notes |
|---|---|
| Engine Blueprint | The design plan, from the Engineer Table; see [Blueprints and Designs](Blueprints-and-Designs.md) |
| Design Blueprint | Unlocks a power pack or exhaust pack design |
| Power Pack, Exhaust Pack | Sub-assemblies of an engine |
| Combustion Chamber, Bell Nozzle, Aerospike Plug | Parts of an exhaust pack |
| Injector, Injector Grid, Turbine | Parts of a power pack. There are versions for each of the nine materials (Andesite … Hastelloy) |
| Engine Wall, Rib, Turbine Shaft, Blisk | The basic parts, again one set per material |
| "Incomplete …" items | Intermediate items used by Create's sequenced assembly; you will see them on belts while a part is being built |
| Copper Coil | Ingredient of the Mechanical Electrolyzer |

How these fit together: [Engine Crafting](Engine-Crafting.md).
